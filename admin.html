// How to get your free GitHub Token (2 minutes)
  1. Go to github.com → sign in (or sign up free)
  2. Click your profile picture → Settings
  3. Scroll to the bottom → click Developer settings
  4. Click Personal access tokens → Tokens (classic)
  5. Click Generate new token (classic)
  6. Give it a name like portfolio, set expiration to No expiration
  7. Tick only the gist checkbox
  8. Click Generate token → copy the token shown
  9. Paste it below and click Connect & Sync
// How it works
Your portfolio data is saved to a private GitHub Gist. Every time someone opens your portfolio it fetches that file automatically.

Images are hosted on Cloudinary (already configured). The token is stored only in your browser — never shared.
